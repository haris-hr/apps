# App support: support pages and privacy policies

This repository is published with GitHub Pages at https://haris-hr.github.io/apps/. App Store Connect and the apps themselves link to these pages, so keep every address working.

| App | Support URL | Privacy Policy URL | Made from (private repository) |
|---|---|---|---|
| Analogion | https://haris-hr.github.io/apps/analogion/support/ | https://haris-hr.github.io/apps/analogion/privacy/ (terms: `/terms/`) | `analogion`: built into `site/` by `python3 tools/site/build_site.py` from `content/store/` |
| Bust | https://haris-hr.github.io/apps/bust/ | https://haris-hr.github.io/apps/bust/#privacy | `bust`: `docs/app-store/site/` |
| ClinchGym | https://haris-hr.github.io/apps/clinchgym/support/ | https://haris-hr.github.io/apps/clinchgym/privacy/ (terms: `/terms/`) | `clinchgym`: built into `docs/site/` by `npm run build:site` from `docs/` |
| Fortyfall | https://haris-hr.github.io/apps/fortyfall/ | https://haris-hr.github.io/apps/fortyfall/#privacy | `fortyfall`: `ios/store/site/` |

**To update a page:** edit it in the app's own repository (that copy is the one to change), then copy the folder over the one here and push to `main`. GitHub Pages publishes the change within a minute or two.

These pages hold only text and images: no scripts, no trackers, nothing that collects data from visitors.
